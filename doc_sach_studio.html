🛠️ Đọc Sách Studio (Teacher Version)

Công cụ này hoạt động 100% OFFLINE trên máy của bạn (Local First). Nó tự động đọc file Excel (.xlsx) chứa nội dung bài học và dịch thành mã JSON chuẩn hóa (data-snapshot.js) để hệ thống web hiển thị.

1 Nạp Dữ Liệu Excel (XLSX)

Nếu bạn chưa có file Excel chuẩn, hãy tải file mẫu TẠI ĐÂY.

2 Bảng Phân Tích Lỗi (Validator)

Chưa có dữ liệu. Vui lòng chọn file ở Bước 1...

3 Xuất Bản Snapshot

Nếu bảng phân tích báo lỗi màu đỏ, nút này sẽ bị khóa. Hãy sửa file Excel và nạp lại. Nếu màu xanh, bạn có thể tải file về.

👉 Hướng dẫn: Tải file này về và lưu đè lên file data-snapshot.js cũ trong thư mục code Web (nằm trong thư mục /js/ hoặc thư mục gốc).
