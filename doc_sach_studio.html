1 Nạp Kho dữ liệu hiện tại (Snapshot cũ)

Nếu bạn muốn xem danh sách bài cũ, xóa bớt bài hoặc gộp bài mới vào kho cũ, hãy chọn file data-snapshot.js hiện tại của bạn.

Chưa nạp kho cũ. (Hệ thống sẽ tạo kho mới tinh nếu bạn bỏ qua bước này).

2 Quản Lý Kho Bài Học Hiện Có

Danh sách các bài đang có trong bộ nhớ (sẽ được xuất ra file data-snapshot.js). Bạn có thể bấm Xóa ở bất kỳ bài nào.

Chưa có bài học nào trong kho. Hãy nạp file ở Bước 1 hoặc Bước 3.

3 Nạp Thêm Bài Mới (Excel hoặc TSV)

Chọn file Excel chứa bài đọc mới cần gộp thêm vào kho.

Copy dữ liệu từ AI và dán thẳng vào ô bên dưới.
